# To Do When

To Do When is a task management application that integrates with a weather API to provide real-time weather updates. The app allows users to add, remove, sort, and filter tasks.

## Features
- Add and remove tasks
- Mark tasks as completed
- Sort tasks by date
- Filter tasks as completed
- Fetch real-time weather updates

## Technologies Used
- Node.js
- Cypress (for testing)
- Fetch API (for handling requests)

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/ZanetaBor/To_do_when.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the application:
   ```sh
   npm start
   ```

## Running Tests
To run Cypress tests:
```sh
npx cypress open
```
